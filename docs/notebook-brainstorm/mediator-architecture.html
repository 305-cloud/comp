Mediator Architecture

Build a machine that, once it has watched a user long enough to predict their own decisions accurately, can act on the 1s-and-0s digital world as their proxy — and knows, precisely, when it hasn't watched long enough yet. This is how the seven notebook pages link into one loop, not six separate ideas.

Reading each node

Digital World
page 6, “x = digital world”
Not a component — the substrate everything else operates on. Defined precisely as “everything that exists in 1s and 0s,” not scoped by how consequential it is. Both where a request originates and where a mediated action lands.
Perception
page 3, Case 1
Input arrives, gets accepted, and is remembered or searched against what's already known. Built as agents/retriever.py + memory/store.py, feeding raw episodic events toward the Trust Engine.
Trust Engine
page 1, the math
Not just clarification logic — this is how the system knows whether it has trained enough on this user to predict their decision. belief.py's concentration is literally "how much evidence," and gate.py's adaptive gate is the ask-vs-act line.
LLM Transformer
page 6, “z = LLM transformer”
A satellite utility, not a pipeline stage: called by Perception to draft a reply, and by the Mediation Layer when it needs to generate something novel rather than replay a learned pattern. Built as llm/gemini.py and llm/adk_backend.py.
Mediation Layer
page 4 & page 7, “decisions on behalf of the User”
Only reachable through the Trust Engine's "act" branch — it never fires from raw confidence alone. This is the biggest gap: Companion today only replies, it doesn't act on anything in the digital world yet.
Verification
page 3, Case 2, the satisfaction curve
Checks whether the mediated action actually matched what the user would have chosen. feedback.py and metrics.py capture the raw signal; the satisfaction score that should drive the two feedback arrows out of this node isn't wired up yet.
Training Loop
page 2, “compare this two processes”
Runs the user's real process and the Agentic AI's predicted process on the same input and scores how closely the prediction matched — ground truth, not a subjective contest. Nothing like this exists in the repo yet.
Idealized End-to-End
page 8, the stacked neural nets
The purest version of the whole thesis — one jointly-trained function predicting the user's decision directly. Can't be built before Verification produces a real reward signal, since nothing can backprop through a hosted LLM call.
